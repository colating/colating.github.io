# Colating general human language 

人类通用语言文字创造：科极语

下一代拉丁语。

The next generation latin language.

In creating ... ...

人类科技不断进步到了今日，已经让现有的有效通用概念标记号在数量上难以应对了。

伴随着 AI人类创造概念时代的即将到来，必将加剧对有效通用概念标记号的需求总量。


**通用拉丁语的本质**
- 有限基数的数学计数系统
  - 概念标记号的图形标记：单词的字符串标识，优选的可变长度的数值。
- 有限音素的语音声节系统
  - 概念标记号的语音标记：单词的语音流标识，优选的可变长度的声节（类似音乐中的音节）。
  
**人类通用语言文字的本质**
- 概念对象、或概念映像的人造标记号。
  
 
就像手机、汽车、飞机等等那样，人类通用语言文字的创造者，是人类自己。
